Written by the Taiga MCP itself when the addressee acknowledges a continuation as handled (`taiga_continuation_ack`, ack=handled). It is durable, auditable evidence that this exact continuation was handled, kept on the card the continuation is about so that the disposable continuation ledger can be rebuilt without resurrecting handled work. It never changes the card status, grants no authority and is not acceptance or completion of anything. Author is the authenticated actor who acknowledged.

Header metadata: the MCP writes the common header of every governed artifact (status movement, Schema, Author from the authenticated actor, Model and Effort). The marker is generated by the MCP and is not callable.

## Fields
- `continuation_id` (text, header, label=Continuation): Exact continuation id that was handled.
- `continuation_type` (text, header, label=Type): Continuation type (for example TASK_DONE).
